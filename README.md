# pulse

Strip health dashboard for a 1920×440 monitor. Tauri 2 — not Electron.

```powershell
cd C:\dev\pulse
npm install
npm run tauri dev
```

Starts at 960×440 on the left (Translate keeps the right). **Half** / **Full** snaps width. Edit [probes.toml](probes.toml) for URLs and launch commands.
